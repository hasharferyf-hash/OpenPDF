OpenPDF - portable version
==========================

Run OpenPDF.exe. Nothing is installed and nothing is written to the registry.
Settings are stored in the "OpenPDF-data" folder next to the program
(because of the OpenPDF.portable file).

Requirement: the Microsoft Edge WebView2 Runtime. It is part of Windows 11 and
is installed on practically every Windows 10 computer. If it is missing,
OpenPDF says so and offers to open the download page.

Fully self-contained use (computers without WebView2):
download the "Fixed Version" x64 runtime from
https://developer.microsoft.com/microsoft-edge/webview2/ , extract the .cab
file and place the extracted folder next to OpenPDF.exe (or rename it to
"WebView2"). OpenPDF uses it automatically.


OpenPDF - גרסה ניידת
=====================

מפעילים את OpenPDF.exe. שום דבר לא מותקן ושום דבר לא נכתב לרישום (Registry).
ההגדרות נשמרות בתיקייה "OpenPDF-data" שליד התוכנה
(בזכות הקובץ OpenPDF.portable).

דרישה: רכיב Microsoft Edge WebView2 Runtime. הוא חלק מ-Windows 11 ומותקן
כמעט בכל מחשב Windows 10. אם הוא חסר, OpenPDF תודיע על כך ותציע לפתוח
את דף ההורדה.

שימוש עצמאי לגמרי (במחשבים בלי WebView2):
מורידים את גרסת ה-"Fixed Version" ל-x64 מהכתובת
https://developer.microsoft.com/microsoft-edge/webview2/ , מחלצים את קובץ
ה-.cab ומניחים את התיקייה שחולצה ליד OpenPDF.exe (או משנים את שמה
ל-"WebView2"). OpenPDF תשתמש בה אוטומטית.
